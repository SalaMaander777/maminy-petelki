- Реализовать сейчас: `/` (главная) и `/catalog`. Остальные пункты пока ведут на заглушки-якоря (`/#masterclasses` и т. д.); содержимое страниц уточняется у владелицы.
- Главная **без каталога**: шапка → большое фото-поле → нить → бегущая строка → контакты.

## Типографика
- Шрифт **Nunito** (400/600/800, кириллица), через `next/font/google`.
- Меню: 24px / 800 / uppercase / letter-spacing .12em (≤900px — 17px, ≤640px — 13px).
- H1 главной 44px (мобайл 26px); H1 каталога 44px (мобайл 30px); H2 подвала 36px (мобайл 28px); название карточки 22px; цена 24px.

## Сетка и размеры
- Контейнер `max-width:1440px`, боковые отступы 80px (мобайл 16px) — **плашка меню, линия под шапкой, фото-поле, сетка карточек и подвал стоят по одной линии**.
- Плашка меню: `width:100%`, `border-radius:999px`, пункты равномерно (`space-around`), область нажатия ≥44px.
- Фото-поле главной: высота 700px (мобайл 520px), радиус 28px.
- Каталог: 3 колонки → 2 (≤900px) → 1 (≤640px); gap 48/32px; фото карточки 4:5, радиус 20px.
- Карточка: фото, название, описание, **Размер / Материалы / Срок**, цена, кнопка «Заказать» (ведёт к контактам).

## Анимации
Easing по умолчанию `cubic-bezier(.2,.7,.2,1)`.
1. **Загрузка**: кремовый экран с вращающимся клубком, качающимися спицами и разматывающейся нитью, подпись «Вяжем уют…»; держится ~1.8s, исчезает 0.7s. Остальные анимации входа стартуют после неё (+1.2s).
2. **Вход**: шапка `drop` (−18px→0, .9s), карточка и кнопка на фото `rise` (+28px→0, 1s), карточки каталога `rise` со ступенчатой задержкой.
3. **Нить**: волнистая розовая линия (5px) + золотой пунктир (2px) между фото и бегущей строкой, рисуются через `stroke-dashoffset` 3.2s.
4. **Бегущая строка**: «Ручная работа · Вяжем на заказ · С любовью · Уют в каждой петельке», 28s linear infinite, `aria-hidden`.
5. **Меню**: при наведении/фокусе и для текущей страницы — розовый пунктирный «стежок» под пунктом (scaleX 0→1, .45s).
6. **Логотип**: при наведении покачивается (`wobble` .8s).
7. **Фото-поле**: фон медленно дрейфует (translateX), карточка на нём «дышит» (`float` 7s), кнопка пульсирует розовым ореолом (`glow` 3.2s).
8. **Кнопки**: заливка слева направо при наведении (.45s); значки мессенджеров в подвале покачиваются.
9. **Карточки каталога**: hover — подъём −8px, тень, зум фото 1.07 (.8s), плашка «Вяжем на заказ».
10. **Сердечко** на фото: переключатель «сохранить» (`aria-pressed`), подпрыгивает (`pop` .5s) и закрашивается; состояние хранить в `localStorage`.
11. **Переходы между страницами**: плавное появление нового экрана (Framer Motion), без пересвета.
12. Анимируем только `transform`/`opacity` (исключения: `stroke-dashoffset`, `box-shadow` у ореола). **`prefers-reduced-motion`**: все анимации и загрузочный экран отключены.

## Доступность и SEO
- Контраст текста ≥ WCAG AA, `aria-label` на иконках, видимый `:focus-visible`.
- Один `h1` на страницу, семантика `header/nav/main/footer`, `lang="ru"`, мета-теги и OG на каждой странице.

## Данные и заглушки
- Каталог берёт данные из JSON/конфига (поля: `name`, `description`, `size`, `materials`, `leadTime`, `price`, `photo`). Реальных данных нет — оставить плейсхолдеры `[…]`, фото — розовые заглушки с узором. Список изделий из макета (плед, шапка, свитер, носки, игрушка, шарф) — **пример**.
- Текст «Вязаное с душой, связанное вручную…» и строка бегущей ленты — черновые, согласовать с владелицей.
